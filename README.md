# Christian Grimberg

**Jefe de Sistemas | Cloud, automatización e IA aplicada**

<img src="./img/gridbar.png" alt="" width="100%" />

Trabajo para que la tecnología resuelva problemas concretos y acompañe la evolución del negocio. Como Jefe de Sistemas en Laboratorios Novocap, combino el liderazgo del área con el trabajo técnico: desde diseñar infraestructura hasta desarrollar soluciones y automatizar procesos.

Mi experiencia en la industria farmacéutica abarca infraestructura cloud e híbrida, integración de sistemas y continuidad operativa. Incluye proyectos como la implementación de SAP S/4HANA y soluciones de automatización y respaldo con .NET, SQL Server y PowerShell. Azure DevOps también forma parte de las tecnologías que utilizo en mi trabajo.

Hoy trabajo además en iniciativas con Microsoft Fabric, Microsoft 365 Copilot y Copilot Studio, explorando cómo los datos y la IA pueden simplificar tareas y aportar herramientas útiles a la organización.
